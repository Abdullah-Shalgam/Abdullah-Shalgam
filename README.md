### 👨‍💻 نبذة عني (About Me)

أنا **عبدالله شلغم**، طالب هندسة برمجيات مهتم ببناء برمجيات متينة وقابلة للتوسع باستخدام **C++** و **C#**. أقوم بدراسة المناهج البرمجية العميقة وتطبيق الهيكلية الموجهة للكائنات (**Object-Oriented Programming**)، هيكلة البيانات (**Data Structures**)، وتصميم الواجهات البرمجية وتطبيقات سطح المكتب (**WinForms**).
